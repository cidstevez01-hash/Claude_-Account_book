# 内容分析

六个App主题卡片名称。PigBang是品牌，其余为视觉风格和季节主题，冬雪两版为同一主题的金/银配色。

自然日语重点：ノスタルジー并非误译，但作为样式标签不如レトロ直接；夏・花火的并列可用助词の连接；丹楓偏汉语文学修饰，在主题UI里显得生硬；冬雪并非最自然的日语主题称谓，长片假名还挤占窄卡片。

保留中文原名、主题key、品牌和季节含义。日文采用自然短名，不增加商品、会员等级或功能含义。冬雪须保留冬季联想及金/银区分，避免误用常作春季季语的淡雪。

语言依据：[小学館デジタル大辞泉／雪明り](https://kotobank.jp/word/%E9%9B%AA%E6%98%8E%E3%82%8A-3229077)、[淡雪](https://kotobank.jp/word/%E6%B7%A1%E9%9B%AA-429006)。辞典用于核对词义/季节含义，不代表辞典认可本组设计命名。
