# 卡面改图规则

记账 App 里用来区分用户自己各张卡的卡面图。每张卡单独开子文件夹（如 `card-faces/xxx/`），内部同样分 `final/` / `history/`。只存仓库，不发布公开 Artifact。

## 输入
1. **原图**：要修改的现有卡面
2. **参考图**：同一角色的全身/完整立绘
3. **替换指令**：由用户每次指定（例：三井住友 + VISA → mercard + JCB）

## 规则
1. **只换品牌标志**：按指令替换发卡方标志、卡组织标志（及随之去掉的版权小字等），其余元素（角色、iD/非接触图标、联名作品标志、背景装饰、底色）一律保留原样。
2. **比例不变**：保持原图横版银行卡比例和尺寸，不套用 1:1 图标规范。
3. **角色被标志遮挡/破坏的部分，用参考图补全**：去掉旧标志后，若露出或破坏了人物图像，把参考图对齐（缩放/平移到与原图角色重合）后直接取对应像素补上。**不许 AI 凭空猜测重画**，避免改坏。
4. **标志用素材贴合，不用 AI 生成**：旧标志用代码擦除，新标志用清晰的标志素材贴上，保证文字/图形不变形。只有参考图也覆盖不到、确实需要补画的背景区域，才考虑 `baoyu-image-gen`，且要先跟用户确认。

## 示例
`_example-voltaction-mercard-jcb/`：`1-original.webp` + `2-reference-fullbody.webp` → `3-result.webp`
- 左上 `MITSUI SUMITOMO CARD` + `©A/N` → mercard 标志
- 右下 VISA → JCB（VISA 压在角色袖口上，去掉后露出的袖子部分即按规则 3 从参考图补全）
- iD、非接触图标、VOLTACTION、黄色几何装饰、角色、底色不变
