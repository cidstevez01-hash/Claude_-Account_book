# voltaction-red-mercard-jcb

红底 VOLTACTION 卡面（mercard + JCB）。用户提供的已换标版本上做两处修正，其余像素不动。

- `final/card.webp`：成品，1586×992，无损 webp
- `history/v1-white-rim-and-copyright.webp`：修正前版本（用户提供）

## 修正内容
1. **mercard 图标白边**：按图标红色区域拟合各边直线，求交得到六边形顶点并抗锯齿重绘边缘；蓝色圆点按面积拟合圆重绘边缘；边缘外侧白边处用附近干净背景的纹理填回。图标内部白色 m、蓝色圆点内部像素未改。
2. **删除「© A/N」**：用同一行右侧 300px 处的干净背景块覆盖，羽化边缘。
3. 校验：与修正前逐像素比对，改动只落在图标周边和 © A/N 两块区域。
