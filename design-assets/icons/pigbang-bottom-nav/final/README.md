# PigBang 底部导航图标

本轮采用用户确认的 2026-11-03 六图标样本中的记账本、明细、统计三个造型，将其整理为透明、可换色的 SVG。原始生成图留在 ../history/20261103-01/。

- `book.svg` / `history.svg` / `bar_chart.svg` 与 `washi-ledger/src/icons/themes/shared/navigation/` 接入内容一致。
- 默认与怀旧主题使用现有的选中/未选中语义色，书脊、书签和纸页使用主题配置中的强调色。
- 夏·花火使用原有暖金至珊瑚色渐变及 bare 呼吸光效，动画相位跟随真实时间，切 tab 不重新从零开始。
- 选中气泡、标签、点击区域、24px 图标外框及导航行为保持原有实现。
- `index.html` 包含真实组件截图及三主题预览；PNG 为 256×256 透明导出，运行时使用 SVG。

本轮不重新请求生图 API；旧原图只作为确认过的造型参考。
