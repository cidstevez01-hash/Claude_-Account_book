夏 · 花火主题 · 图标系统设计稿(重构版)

图标 / 光效 / 颜色——三层分离

按要求重新搭了一遍结构：图标(纯路径数据，ICONS注册表)、 光效(独立CSS class，.ring-glow / .nav-tab-glow / .rate-fab-glow-* / .drawer-row-icon-glow)、颜色 (只有一处#icon-fill-grad渐变定义)——三者互不耦合，换图标只改 ICONS里一条数据，换光效只改对应class，换颜色只改那一个渐变定义， 不会再出现"改一处牵连全部重新生成"的问题。仪表盘这次是Stitch重新设计的书本 图标(潦草手绘线稿风格，跟其他图标同一套渐变)，全主题通用，不再用grid_view。
