## 已定位原因

- autumn.css 的 app-shell::before 使用 top: env(safe-area-inset-top)，把背景装饰也避让到状态栏下方；AppLayout 对交互内容另有独立安全区内边距。背景应延伸到顶边，交互内容仍保留安全区。
- app-shell:has(input)::before 将带输入框的整页叶丛缩为 145px、透明度降到 .32。首页日期输入框也会匹配，导致首页错误缩小。
- 单叶资源只被余额卡片水印使用，没有页面散叶层。
- 余额卡片背景为 95% 白色；分类图表卡片背景为完全不透明白色。原 autumn 卡片选择器并未覆盖图表卡片。

## 本次预览

- 叶丛贴到视口顶边（top: -18px），随页面宽度缩放 260–330px；390px 页面为约 289px，不因 input 改变。
- 复用现有单叶贴图，补充五个不同位置、角度的静态散叶，不生成新素材。
- 页面纸纹略加强；余额、图表及条目卡片统一 55% 不透明度（即 45% 透出背景），日期栏 65%、导航 80%。文字本身不降透明度。不套用花火的 10px 模糊，以保留纸纹和细线叶片。
- 图标、标题、金额布局和业务逻辑不调整。
