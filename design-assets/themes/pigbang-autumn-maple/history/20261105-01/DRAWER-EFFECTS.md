# PigBang 红叶主题 · 抽屉菜单

状态：设计效果图，未接入 App。Image 2，quality=low。参考 20261104-02 线稿版。

布局依据：`washi-ledger/src/design-system/components/NavDrawer.tsx`。左侧宽度 78%、最大 320px；右侧显示变暗、轻模糊的首页。四项依次为汇率换算、日历、设置、关于。无额外账户入口、尾部登录/注册按钮或菜单箭头。

| 位置 | 资源 | 红叶效果建议 |
|---|---|---|
| 汇率换算 | currency_exchange | 24px，铜色轮廓柔光，模糊2–3px；不加圆底 |
| 日历 | calendar_month | 同上 |
| 设置 | settings | 同上；区别于设置页内部实际有圆底的行图标 |
| 关于 | info | 同上 |
| 未登录头部 | menu_book | 44px真实圆形边框，24px图标；仅极弱外沿光，不叠轮廓光 |
| 已登录头部 | 原头像 | 44px原图，不染色；如发光，定位在真实头像外沿且不被裁切 |

静态展开态四行均不高亮。按下某行后显示浅纸铜色底与较深文字，延续现有150ms反馈后跳转；不画成永久停留的选中页面。光层可6.5秒低幅呼吸，图标主体保持不动；按统一时间轴负延迟避免重挂载跳变。减少动态时关闭呼吸与缩放。

抽屉遮罩沿用现有约40%暗色、2px模糊；进入/退出约300ms。装饰线稿只在空白边角，无填色、无漂浮粒子，不覆盖菜单文字。实际交互以代码为准，效果图中的光效强度为静态表达。
