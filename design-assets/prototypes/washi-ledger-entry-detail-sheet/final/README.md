# R-40 查看详情弹层 · 设计参考

Stitch项目 `projects/15184015355220157714`（"washi-ledger 记账条目详情弹层"）生成的概念图，
用于确认弹层结构（分类图标+金额、日付/支払い方法/タグ/メモ/獲得ポイント明细行、レシート卡片）。

**注意**：图中底部的「編集」「削除」按钮未被采用——用户确认方案时明确要求"不要把编辑及
删除按钮放进来，这只是详情"。实际实现（`washi-ledger/src/features/ledger/EntryDetailSheet.tsx`）
是纯只读弹层，编辑/删除继续走EntryCard展开抽屉原有入口，不在详情弹层里重复提供。
